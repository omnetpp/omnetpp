Python API
==========

OMNeT++ ships a Python package, ``omnetpp.scave``, for programmatic access to
simulation results. It is the API used by the Analysis Tool in the Simulation IDE
and by ``opp_charttool`` to load ``.sca`` and ``.vec`` result files into Pandas
data frames, apply operations to result vectors, and produce charts.

The pages below document the public modules of the ``omnetpp.scave`` package. The
reference is generated automatically from the package sources.
