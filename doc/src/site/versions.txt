# OMNeT++ documentation version manifest
#
# One version per line: "<label>  <git-ref>"
#   <label>    URL path segment and display name, e.g. 6.x -> docs.omnetpp.org/6.x/
#   <git-ref>  git branch or tag to build the documentation from
#
# The FIRST non-comment line is the DEFAULT version: it is published at the site
# root (docs.omnetpp.org/) as well as under its label.
#
# Only refs that already contain the Sphinx-based doc build system (doc/src, this
# site/ directory) can be built. Old, LaTeX-only release tags are not supported.
#
# In v1 only the first line is built. Additional lines are read but not built yet;
# uncomment/add them once multi-version publishing is enabled.
